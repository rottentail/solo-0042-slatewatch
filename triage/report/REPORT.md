## 8. 分类结论

### 8.1 可用现存材料排除“只是留边或抽图配置不同”

- **E1** ZIP 卡片证据里 2.033 / 2.100 / 2.167 三个显示时标对应三张不同画格。  
  结论：排除：三者共用源帧 1.000 s，且三份成员像素逐字节相同。  
  依据：映射 source_us = [1000000, 1000000, 1000000]；成员像素一致 = True；唯一配置 = [{'hit_id': 'hit-a89fff29594a5b04dff1221a', 'kind': 'sound_gap', 'channel': None, 'start_us': 2000000, 'end_us': 2200000, 'padding_ms': 0, 'frames': 3, 'all_labels_in_picture_coverage': True}]；该唯一配置的每一个目标都落在归档画面覆盖内 = True；其它候选能否产出同样三个时标 = []
- **E2** 网页画格与 ZIP 卡片画格属于同一候选、同一画面，只是留边或抽图配置不同。  
  结论：排除“同一候选同一画面”：ZIP 自己的证据已把 3.300 s 记在洞条目下，画格为 null；归档扫描在该时标也无画面，任何配置都取不出画格。  
  依据：ZIP 内 3.300 s 的目标 = [{'entry': 'hit-d39b6e57dd894caabe952cfe', 'target_us': 3300000, 'source_us': None, 'file': None}]；归档画面覆盖 = [{'end_us': 3200000, 'start_us': 0}, {'end_us': 4000000, 'start_us': 3600000}]，覆盖 3.300 s = False；冻结扫描上命中 3.300 s 的配置数 = 2440；这些配置在该时标都落在画面洞 = True
- **E3** 3.300 s 那张网页画格可以靠调留边或帧数从归档版取出。  
  结论：排除：归档画面覆盖在 3.2–3.6 s 为空，该时标不可能产出画格。  
  依据：画面覆盖 = [{'end_us': 3200000, 'start_us': 0}, {'end_us': 4000000, 'start_us': 3600000}]；覆盖 3.300 s = False；冻结扫描上命中 3.300 s 的配置数 = 2440；这些配置在该时标都落在画面洞 = True

## 9. 增加哪条观察可把未知变成可判

- **U1**：增加“另存画格时一并抄下“源帧”时标，或保留预览 token 与映射” → 1.000000 归归档版；1.040000/3.280000 归 current；U1 从未知变可判（对照 control/frozen-card-target-2.100.json 与 control/current-long-target-2.100.json）
- **U2**：增加“保存时截下含“节目时标 + 源帧”两行的整页，或保留 token 对应的映射” → 手抄值可与映射对齐核对，C1/U2 不再依赖单一手抄行
- **U1 的全分辨率分支**：增加“归档母带字节，或封包内保留源栅格而不只是 80x48 缩略图” → 可做全分辨率比对，决定两帧是否同一物理帧
- **R1**：增加“按索引 master_sha256 核对归档母带字节” → 可直接复测覆盖与空洞，R1 由记录级升为母带级
- **R2**：增加“封包描述符（含整包 sha256）” → 可重算整包摘要，R2 变可判

## 9.1 三类结论之间的关系

- C1 与 U1 不矛盾：C1 只用“手抄页面时标 3.300 s + 归档画面覆盖为空”判定版本，不依赖像素归属到某一源帧；U1 说的是反过来——单看这份浏览像素，无法指认它究竟由归档 1.000 s、当前 1.040 s 还是当前 3.280 s 的源栅格生成。
- 同一条浏览像素在 current 内部就对应两个全分辨率不同的源帧（1.040 s 与 3.280 s），因此浏览尺寸像素相同本身不构成“同一物理帧”的证据。
